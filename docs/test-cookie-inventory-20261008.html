8 October 2026 • TEST only • Source checkpoint f415c471755fb0467fd6c8daf5ffd3b7b94d2b0b • WooCommerce 10.7.0 / WordPress 6.8.10

This factual inventory supports VirtualJog review. It does not determine the legal basis for processing and does not replace approved legal wording. No cookie values, session tokens, customer addresses or credentials are included.

Scope and evidence

Browser inspection covered anonymous homepage, Contact, product, cart, checkout, login/My Account and a dedicated logged-in QA customer. Separate fresh HTTP cookie jars observed login and basket/session response headers. HTTP requests do not execute JavaScript. The embedded browser exposes DOM/scripts but not a cookie jar or local/session storage API; configured entries are deliberately separated from observed cookies. The four relevant WooCommerce JavaScript source files were hash-matched to the running TEST source.

The anonymous HTTP reads did not set cookies; this is not proof that JavaScript or third parties set none. Cookie expiry depends on login state and renewal. The site-specific hash and TEST domain must be checked again on any later production environment.
